# Dataset placement

The image dataset is intentionally not committed. Obtain a properly licensed copy, then use this layout:

```text
data/
├── train/
│   ├── Brownspot/
│   ├── Healthy/
│   └── Hispa/
└── valid/
    ├── Brownspot/
    ├── Healthy/
    └── Hispa/
```

Class-folder names must match between the training and validation directories.
